Network Settings

Use Proxies Route connections through proxies.
Remove Proxy After Use Removes the proxy from proxies.txt permanently after it is assigned to a thread. Good for better no flag.
Data Saver Mode Keeps a persistent browser cache (CSS/JS/assets) per worker so Discord assets are not re-downloaded each run. Auth data (cookies, tokens) is always wiped. Reduces usage from ~15MB to ~2-4MB after the first run. (Credit to asem.3)
⚠ Warning: May break hCaptcha on Brave. Custom Fingerprint will not work when Data Saver is ON.

Version History

Track what's new, fixed, and improved in FluxMart.

What's New

Version 3.3.4 Latest

Version 3.3.3

Fixes

  • Fixed Stop button not working for Chromium and Brave browsers — generation now stops immediately when you press Stop
  • Fixed DuckMail verification — verification link now correctly opens the verify page instead of redirecting to discord.com
  • Fixed email verification detection — the tool now correctly recognizes when verification is complete after captcha is solved
  • Fixed captcha loop detection not triggering properly — endless captcha loops are now detected and handled correctly
  • Fixed Speed/TPH calculation — tokens per hour now accurately reflects actual generation speed

Improved

  • Improved email verification speed — faster inbox polling and quicker link detection
  • Improved overall stability — better error handling and thread safety across the entire tool
  • Improved Brave browser stealth — reduced account flagging with better fingerprint masking
  • Updated generator icon in the sidebar navigation

Version 3.3.2

Fixes

  • Fixed Camoufox
  • Fixed token manager bug
  • Fixed custom fingerprint at token manager

Added

  • Added Windows Manager toggle to automatically grid multi-threaded browser windows (Brave, Chromium, Camoufox)
  • Added real username generation
  • Added auto updater

Improved

  • Improved Camoufox

Removed

  • Removed legacy VPN manager files: Windscribe and Mysterium
  • Removed Token Verify toggle from UI (email verification is now always enabled)
  • Removed Thread capability text and renamed UI to Threads

Version 3.3.0

Fixes

  • Fixed rate limit checker: no longer triggers rate limits when checking, now uses a passive detection method via Discord's read-only endpoints
  • Fixed Groq AI model name from gpt-oss-120b to openai/gpt-oss-120b across all files
  • Fixed window.toast compatibility: existing toast calls now work with the new notification system
  • Fixed container display mode: changed from block to flex for proper sidebar layout rendering
  • Fixed animations.css corruption from CRLF/LF mismatches
  • Fixed dashboard session counter: now tracks all tokens (valid + locked + invalid), not just valid
  • Fixed status bar "Workers" label: renamed to "Running" and now shows actual active thread count

Added

  • Added sidebar navigation with SVG icons: replaces the old top tab bar for a desktop-class layout
  • Added collapsible sidebar with state saved between sessions via localStorage
  • Added keyboard shortcuts: Ctrl+1 to Ctrl+7 to switch tabs, Ctrl+G to start generating, Ctrl+B to collapse sidebar
  • Added statistics dashboard on Generator tab: shows Total Generated, Success Rate, Speed (tokens/hour), and Session count in real-time
  • Added toast notifications: animated popups that slide in from the bottom-right with auto-dismiss progress bar (success, error, warning, info variants)
  • Added status bar at the bottom: shows connection status (green/red dot), running thread count, rate limit status, and version number
  • Added glassmorphism (backdrop-filter blur) to cards and settings sections
  • Added skeleton loading CSS classes for future use
  • Added Check Key button for Groq API key validation
  • Added Check Key button for OpenRouter API key validation
  • Added backend check_openrouter_api() Python method in gui_controller.py
  • Added drag-prevention support for new sidebar and nav-item elements
  • Added window.toast compatibility shim so existing code works with new toast system

Improved

  • Improved overall layout from top-tab navigation to a professional sidebar + main content flexbox structure
  • Improved tab navigation bar: centered tabs, refined active indicator (proportional white underline bar)
  • Improved cards with hover border effects and subtle gradient overlays
  • Improved progress bars: slimmer 6px design with smoother gradients
  • Improved settings sections with backdrop-filter blur effect
  • Improved API key inputs: changed from type="text" to type="password" for security
  • Improved version from v3.2.9 to v3.3.0

Removed

  • Removed AI Image Solver: full removal from frontend (HTML, CSS), JavaScript (settings.js), backend (gui_controller.py), config.json, and all workflow files (discord_register.py, discord_register_brave.py, discord_register_chromium.py, mail.py)
  • Removed vision_solver.py and vision_solver_truedriver.py files entirely
  • Removed old top tab navigation bar
  • Removed scroll arrow buttons that were not functional
  • Removed old footer: version now shown in status bar
  • Removed ai_image_solver mutual exclusion logic from save_settings
  • Removed image solver branching from captcha solving flow in all browser methods (Camoufox, Brave, Chromium)
